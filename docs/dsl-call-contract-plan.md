# DSL 函数调用契约与错误处理

## 范围与决策

当前整合基线：aaa6c0f（master），开发分支：refactor/dsl-call-contracts。原方案基于 74dfe70 暂存于 stash；本轮将其整合到最新修复之上。统一参数数量校验与最小错误传播，不扩展全项目日志系统，不修改正常调用的公式和求值顺序。整合结果已获用户确认，代码与本文一起提交。

## 与当前基线的整合

- 保留 Editor 内固定 Creator 实例及下一输入阶段应用配置的规则；SetCreator 继续调用 RequestCreatorConfig，不恢复旧的实例替换。
- 保留 App 先设置帧时长、Runtime 同步面板参数后发布 deltaTime、每帧只执行一次 Update 的顺序。
- 保留运动预设的场景修改限制、执行标记自动恢复及具体预设名称；复用已有错误状态，不重复添加错误处理函数。
- 保留网格配置、stepCount、maxRealDeltaTime、音频和中文字库的后续修复。
- ScriptError.h 已纳入项目，本轮只追加参数数量检查，不重复登记项目文件；stash 保留至整合确认完成。

- 固定参数函数严格匹配数量；当前没有可选参数或可变参数声明。
- 应用内置函数：0 个为 GetBodyCount；1 个为 SetCreator、Ball、CreateConnection、SetConfig；2 个为 CreateBody、Box、RegularPolygon、Cross、Boundary；3 个为 Parallelogram、Trapezoid、FramedBox；4 个为 Gear；6 个为 Strand、Necklace。
- 基础函数和运算符按原操作数数量校验；自定义函数按声明的形参数量校验。自动调用的 Update 必须是零参数函数。
- 原生函数注册时提供参数数量，EvaluateCall 在实参求值前校验，错误调用的实参不产生副作用。应用 lambda 不再重复校验。
- 专用 ScriptError 提供函数名、期望数量、实际数量；调用非函数值也明确拒绝。不捕获任意 C++ 异常。

## 传播与恢复

- SceneScriptRuntime 捕获脚本错误，记录入口上下文和消息；手动执行/属性刷新返回成功与否。解析器不打印或访问 App。
- 任一脚本错误锁住后续自动 Update 和运动预设。手动执行场景脚本、刷新物体/连接脚本会重新尝试；成功后解除错误，失败后继续锁住。重置也清除错误。解除错误不自动取消用户的模拟暂停。
- Body / Connection 脚本失败后，不继续应用本次属性配置。已经执行的共享作用域修改及场景副作用不回滚；脚本文本也不实施事务回滚。
- 运动预设在边界捕获，失败的计算结果不写回；之前成功的预设结果不回滚。其余物理运算完成本帧推进后由 App 暂停，不用异常中断物理循环；本帧后续预设跳过。
- 加载时任一脚本失败即停止加载，关闭文件并报告加载未完成。已载入对象保留，不承诺事务回滚。
- App 在更新、物理推进和 UI 操作后处理错误：暂停模拟；每次新错误只记录一次；使用背景文字区域持续显示错误，优先于脚本 debugString。
- 为安全接收用户函数名，App::AddLog 使用固定格式串输出文本，不把诊断文本当作 printf 格式串。

## 不包含

参数类型与数值范围、完整语法诊断、源码行列追踪、无限循环限制、数组下标校验、脚本副作用事务及全项目日志统一。现有 maxRealDeltaTime 校验仍保持拒绝字段并输出 stderr 的规则。

## 验证计划

- 全部应用内置函数缺参、多参拒绝；正常数量沿用已有实现。
- 基础函数、自定义函数、零参数函数、嵌套调用、非函数调用；错误实参及错误后的语句不执行。
- Update 不自动重试，手动修正后恢复；Body / Connection 失败不应用配置。
- 预设错误不逃出物理回调，不写入失败结果；载入失败停止并释放文件。
- Debug x64 / Win32 构建；既有脚本与拖拽回归。测试位于忽略目录，不提交。

## 实现定位

源码路径相对 Rigid2DSimulation/。

- framework/parse/ScriptError.h：专用异常与共用 RequireArgumentCount 检查。
- framework/parse/Value.h、Value.cpp：原生函数数量元数据；基础函数、原生函数和自定义函数的调用检查。
- current/script/SceneScriptRuntime.h、SceneScriptRuntime.cpp：16 个原生函数注册；脚本执行、Update 与预设的错误边界；错误记录和恢复。自动 Update 保留在场景作用域执行的原规则，不改成普通函数的局部作用域。
- current/common/SimulationApp.h、SimulationApp.cpp：推进前、推进后、UI 操作后处理错误；记录一次日志并暂停，背景显示最近错误。手动 UI 操作产生的错误在下一帧显示。修正后需要用户主动恢复模拟。
- current/storage/SceneStorage.h、SceneStorage.cpp：加载返回成功与否，脚本失败时关闭文件并提前返回；App 记录加载未完成，画面保留具体脚本错误。
- framework/app/App.cpp：AddLog 使用固定格式串，确保用户函数名中的百分号按文字输出。
- 当前基线已登记 ScriptError.h，本轮不修改项目文件及 .vcxproj.user。
