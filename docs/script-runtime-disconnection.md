# 暂停脚本接入

本分支将脚本从当前应用接入中隔离，而非仅停止每帧调用。`SimulationApp` 不持有脚本运行时，不再初始化作用域、执行脚本或处理脚本错误；Body、Connection 不持有脚本文本和程序。物理计算公式、子步数量和原有运算顺序保持不变。

`SceneRenderer::RenderBackground` 移除脚本文字参数及对应绘制，调用方不再传入空字符串占位。

## World 推进

`PhysicsWorld::Advance` 接收时长、拖拽数据和越界通知，不再接收子步开始或单物体推进函数。World 自己依次执行 Body 运动、子步拖拽、几何更新及既有碰撞/连接计算。`Body::Step` 删除脚本预设参数，不再传空回调。越界通知仅用于编辑器清理轨迹。

## 脚本源码与 UI

DSL 解析器及脚本实现源码保留。专用场景构建、参数数据和配置辅助源码收回 `current/script`。UI 面板不因功能停用而迁移目录：CommandPanel、ParameterPanel 均保留在原有 `current/ui` 子目录，文件顶部说明脚本用途和停用状态；UI 不创建它们，源文件暂不参与构建。上述停用的应用适配源码保留旧模型接口，不是当前可启用的插件，恢复脚本功能时需重新适配，不能只取消构建排除。

普通 UI 不再创建命令、脚本参数面板。Body/Connection 面板移除脚本编辑和应用入口，保留信息、选择及删除功能。Creator 使用普通 C++ 属性配置，不再存储或解析 DSL 的 Value；原 DSL 转换源码保留于脚本目录。

## 纯数据存档

保存物理世界设置、物体形状和属性、连接端点及参数，不保存或执行脚本。加载先读入形状和 BodyProperties，通过 Body 正常构造或 CreatePoint 完成初始化，再通过 World 登记物体与连接。派生量由 Body 计算，存档模块不复制物理公式。

新文件使用 `R2DS` 标识和版本 2，不兼容旧脚本存档，不自动覆盖或转换旧文件。文件版本、记录长度、连接端点检查在重置当前场景之前完成；读取失败保留现有场景。音乐、编辑器交互状态和 App 的帧时长上限不属于此物理场景存档。

本分支不包含音乐模块拆分或 UI 更新/绘制解耦，可独立检查和合并。

## 验证

- Debug x64 应用构建通过；参与构建的非脚本应用源码不再引用运行时、DSL Value 或物体脚本字段。
- 对比修改前的实际目标文件：无拖拽及三种拖拽场景中的位置、速度、转角、角速度、时间和越界通知次数，17 位精度输出完全一致；场景同时包含碰撞、静电和弹簧连接。
- 不链接 DSL/运行时的临时验证通过：七种鼠标创建工具，点、多边形、圆、复合及固定物体的存档往返，四类连接、质量/惯量/几何恢复，以及旧格式和截断文件在重置前被拒绝。临时验证位于忽略的 ref 下，不提交。
