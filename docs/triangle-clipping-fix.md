# 三角形裁剪轴错误与方框缺色

## 问题与来源

用户反馈方框轮廓完整，但内部出现大片未填色区域；截图中的旋转黄色矩形上部有明显缺口。

该问题不是画布职责调整引入的。画布重构已先独立提交为 `20504a1`；修复前 `DrawTriangle.cpp` 与重构前版本完全一致，不依赖画布类型的最小绘制程序也能复现。

历史提交 `0f9c597`（`refactor(draw): replace triangle clipping macro`）将 `EdgeCut` 宏替换为函数时遗漏了坐标轴参数的语义：宏调用 `EdgeCut(a, c, y, x, ...)` 会交换宏内部的 `x`、`y` 标记，实际处理左右边界。提取后的函数却固定比较 `point.y`、计算水平线交点，并同时用于左右、上下裁剪。

因此，左边界 `x=170` 被错误用于判断纵坐标，导致本来位于显示区域内的三角形遭到错误裁剪或丢弃。背景绘制、颜色和深度值并非此次复现的原因。

## 修复范围

- 仅修改 `Rigid2DSimulation/framework/draw/DrawTriangle.cpp` 的私有裁剪辅助函数及四处调用。
- 显式区分 `BoundaryAxis::X` 和 `BoundaryAxis::Y`；左右边界按 x 判断和求交，上下边界按 y 判断和求交。
- 将原辅助函数改为 `ClipTriangleAtBoundary`，交点计算集中在私有普通函数中，不恢复宏、不引入模板。
- 保留现有三角形递归划分、扫描线填充、整数取整及深度测试。不是替换整个光栅化算法，也不宣称修复原注释提到的所有细缝问题。
- 此项是经本轮明确要求执行的正确性修复，与前一项画布重构分开，不作为纯风格整理描述。
