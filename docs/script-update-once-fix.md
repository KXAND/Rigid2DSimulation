# 脚本 Update 单次执行修正

## 问题与决定

基线 e5e4db9，分支 fix/app-logic。

SceneScriptRuntime::Update 原先先执行一次脚本 Update，再同步 Parameters 面板参数，随后再次执行脚本 Update。两次都在物理推进前，并非物理子步或不同的脚本阶段。

旧 Cur::Update/basicUpdate 已存在这个重复调用。此前职责重构保留行为，并不意味着执行两次是必要协议。本轮按用户确认改为：清理待删除参数、同步面板参数、执行一次脚本 Update。

## 实现范围

- 仅修改 Rigid2DSimulation/current/script/SceneScriptRuntime.cpp：移除同步参数之前的脚本调用，更正说明注释，保留同步之后的调用。
- Update 不存在时仍同步参数；参数列表为空时仍执行存在的 Update。
- 面板参数在执行前覆盖脚本同名变量。脚本随后对变量的修改保留至下次同步，不反写面板参数。
- 保留原参数删除行为：删除列表条目，但不自动删除作用域中已有的同名变量。
- 不修改 UI 调度、调试文字读取时点、帧时长写入时点、脚本返回/作用域规则或物理算法；不兼容旧的每帧两次执行行为。
- 历史重构文档中的“两次执行”记录描述当时基线，本文件记录新的执行决定，不改写历史方案。
