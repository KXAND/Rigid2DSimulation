# 全部面板的控件创建整理

## 决策与范围

用户确认 GlobalPanel 示范后，将相同写法推广到全部面板。沿用现有控件、回调和横纵布局，不引入第三方框架、HTML、UI DSL 或通用模板工厂。

每个面板只拥有根布局。子控件由容器独占持有，按显示顺序通过 AddRow、AddColumn、AddTextBox、AddLocalizedButton 等接口创建。回调紧跟控件创建；仅在后续确实需要访问时保存借用指针，不再把每个按钮、分隔线、行重复列成成员。

## 修改清单

| 面板 | 整理方式 |
| --- | --- |
| GlobalPanel | 保留已确认的保存行、加载行示范，只借用两个路径输入框 |
| BottomPanel | 根横向布局添加三个标签，仅保留 Update 使用的标签引用 |
| AboutPanel、LanguagePanel、CommandPanel | 直接添加文字、语言按钮、脚本输入框和编译按钮，不保存只在构造时使用的控件 |
| MenuPanel | 按模拟按钮、场景面板入口、模式按钮、辅助面板入口组装，保持原显示次序 |
| CreationPanel | 直接添加工具按钮、尺寸输入框和说明，删除重复的按钮数组 |
| BodyPanel、ConnectionPanel | 根布局持有可隐藏的编辑区和详情；编辑区内创建脚本框与操作行；不再手工拼接裸指针列表 |
| ParameterPanel | 每行按名称与删除按钮、滑条与数值、分隔线组装，删除重复保存整组控件的 ParameterRow |

## 容器与生命周期

- 横纵布局共用 ControlList 的创建及所有权代码，布局计算仍各自保留原算法。
- Add 接管非空 unique_ptr；对象位于堆上，容器扩容不改变控件地址。借用引用在 Clear 或所属容器销毁后失效。
- GetSize 返回全部已创建子项数；GetControls 返回只读的可见子项视图。移除旧的裸指针构造器和可写 controls，不保留两种所有权方式。
- SetVisibleCount 仅显示前 N 个子项。新隐藏项先 Discard 清理输入焦点，实例保留供复用；隐藏项不参与测量、输入遍历与更新。动态行只在数量超过缓存时创建。
- 全部子项可见时 Add 的新子项也可见；存在隐藏项时，新子项暂不显示，由 SetVisibleCount 一并选择。这保证缓存布局保持前缀顺序。
- Clear 先 Discard 可见子树，再销毁全部子项。普通析构只释放所有权，不保存 App 引用。面板关闭仍清理焦点但保留布局。
- 不允许在正在遍历的回调内 Clear 或改变同一容器的可见列表。参数新增、标记删除、选择变更依旧在原同步位置更新布局，不在点击中销毁自身。

## 保持不变

坐标、间距、宽高、滚动处理、绘制和回调顺序不变。横向布局累加子项宽度，纵向布局累加子项高度；控件内部间距仍计入其尺寸。

Body/Connection 草稿仍在编辑期间写回，Command 和参数文本仍在编辑完成后写回；滑条仍按原像素位置量化。详情与创建帮助仍在前面的控件处理之后读取。

参数与连接行仍按索引绑定当前数据，减少时隐藏并清理焦点，增加时复用已有实例。选择切换清理旧编辑状态，无选择时只显示详情提示。不会因本次整理修改场景数据或业务规则。
