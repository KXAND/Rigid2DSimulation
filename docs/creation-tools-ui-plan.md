# 创建工具 UI 入口

## 本轮范围

基线：ae42dc8。分支：feat/creation-tools-ui。用户确认采用独立创建面板，在左侧菜单增加入口。实现已获用户确认，代码与本文一起提交。

- 提供方框、圆、板、粒子、连接、点、钉住物体七种已有工具；按钮直接切换到创建模式。
- 编辑粒子半径和板厚；圆的半径仍由拖动确定，不受粒子半径输入框影响。
- 显示当前工具、是否处于创建模式和对应鼠标操作说明。打开或关闭面板本身不切换模式。
- 数值编辑回车或点击面板内别处确认；只接受完整的有限正数，否则保留旧值。沿用现有 TextBox 的编辑流程，仅在本面板的数值框增加回车确认，不添加框架级输入机制。
- 配置仅作用于之后创建的对象，不修改已有对象；工具切换取消未完成的旧创建过程。

## 职责与实现

- current/ui/creationPanel/CreationPanel：组合控件，不负责创建物体或模拟。
- CreationButtons：一种带工具模式参数的按钮，复用七次，不为每种工具建立独立子类。
- CreationControls：尺寸输入、当前工具与说明；沿用现有控件继承接口，不顺带进行 UI 回调化。
- SceneEditor：提供类型化 CreatorConfig 请求入口，以及读取待应用配置的入口；同帧的尺寸与工具修改在最新请求上继续修改，不能相互覆盖。
- SceneEditor::SelectCreationTool：保留其他配置，只改变工具模式并进入创建模式、取消拖拽。Creator 配置仍在下一次 PreUpdate 的拾取之前生效，不替换 Creator 实例。
- DSL 的 SetCreator 仍解析 Value 后提交同一请求；UI 不拼接或执行 DSL 文本。
- UserInterface、MenuPanel 和项目文件登记新面板；localization.txt 添加中英文文本，保持现有资源编码 GBK 和 CRLF，C++ 使用 UTF-8 BOM 和 CRLF。

## 保持的行为与边界

- 方框仍要求向右下拖动；圆从圆心向外拖；板沿长度方向拖动；粒子与点单击创建。
- 连接从一个物体按下、在另一个物体上释放；沿用现有连接配置。钉住工具沿用原有创建点物体与刚性连接的实现。
- 不修改形状构造、物理公式、输入阶段顺序、暂停规则、存档格式或旧 DSL 配置含义。
- 不新增连接种类选择、物体属性检查器、示例场景、字体后端或控件框架重构。这些是后续工作。
- 现有字库缺字问题仍在标准字体迁移待办中，本轮不通过字体机制修改解决。中文创建按钮附带英文工具名，以免已有缺字影响辨认。
- UI 更新仍晚于场景输入：点击画布结束数值编辑的当次场景操作可能使用旧值，未完成的创建还会在下一次配置应用时取消。因此提示用户先回车或在面板内确认，再操作画布；不把框架输入阶段重构混入本轮。
